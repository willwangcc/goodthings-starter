# Post-install Review — copy into the participant's ChatGPT

Review my Good Things installation, including any blocked or partially completed steps.

Read the PUBLIC instructions from:
https://github.com/willwangcc/goodthings-starter/blob/main/skills/post-install-review/SKILL.md
and its schema docs/installation-report.md and schemas/installation-report.schema.json.

1. Reconstruct only what you can VERIFY about this installation; ask if important evidence is unavailable.
2. Evaluate T01–T13 in docs/installation-test.md. Label untested and unverified facts correctly.
3. Draft an installation-report.v1 JSON with measured metrics (or null if unknown), a list of independently identifiable frictions, workarounds and next actions.
4. Show me a summary and ask if I want the full report committed to MY private Good Things repository. Do not store it in the public starter.
5. Search OPEN and CLOSED issues in willwangcc/goodthings-starter before proposing a new Issue. Reuse existing matches.
6. For each new actionable problem, prepare a minimal, anonymized PUBLIC Issue draft. Remove all secrets, private repo/deployment addresses, personal information, sensitive logs and screenshots.
7. Show me the EXACT Issue text and ask permission BEFORE publishing each new public Issue. If I decline, keep the draft private. Never publicly disclose security vulnerabilities.
8. Report public Issue links only for issues actually created, then recommend the top three evidence-based installer improvements.

Do not call the installation COMPLETE without a verified unattended scheduled run and successful feedback write-back.
